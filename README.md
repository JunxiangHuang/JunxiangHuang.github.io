# Junxiang Huang — Academic Website

This is an English-first academic website built with [HugoBlox Academic CV](https://github.com/HugoBlox/hugo-theme-academic-cv) and deployed with GitHub Pages.

## Local preview

Install Hugo Extended 0.162.0, then run:

```bash
hugo server
```

## Publish

Create a public repository named `JunxiangHuang.github.io`, push this directory to its `main` branch, and enable GitHub Pages with **GitHub Actions** as the source. The included workflow builds Hugo Extended 0.162.0 and deploys the generated site automatically.

The site is configured for `https://junxianghuang.github.io/`.
